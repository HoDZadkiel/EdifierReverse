# 功能旗標 `0xD8`（DEVICE_FUNCTION_QUERY）

狀態：**靜態分析，未實機驗證**。出處：`lib_connect/model/D8Bean.java`。欄位表由 `scripts/extract_d8_bits.py` 自動抽出，機器可讀版見 `docs/d8-bits.json`。

用途：查詢 `0xD8`（216），空 payload。回應的每個位元組描述裝置一類能力，App 靠它決定顯示哪些功能。**要知道 ES850NB / MP330 支援什麼，第一件事就是送這個查詢。**

規則：`payload[N]` 對應欄位 `bN`；長度不足 N+1 時該欄位保持預設（不支援）。位元編號 `bit0` 為最低位。

## 整位元組欄位

| 位元組 | 欄位 | 意義 |
|--------|------|------|
| 1 | `b1Bat` | 非 0 表示 App 顯示電量 |
| 2 | `b2IsSupportQueryName` | 1 = 支援查詢名稱（`0xC9`） |
| 3 | `b3IsSupportSetName` | 改名字數上限：1→24、2→30、3→29、4→35 |
| 4 | `b4IsSupportQueryMac` | 1 = 支援查詢 MAC（`0xC8`） |
| 5 | `b5IsSupportQueryDeviceVersion` | 1 = 支援查詢版本（`0xC6`） |
| 6 | `b6IsSupportDisconnectA2dp` | 1 = 可由指令斷開 A2DP |
| 7 | `b7IsSupportRepair` | 1 = 支援重新配對 |
| 8 | `b8IsSupportAutoShutdownWithoutAudioInput` | 1 = 支援無音訊自動關機 |
| 9 | `b9TimeOff` | > 0 = 支援定時關機；數值本身另有用途（未查） |
| 10 | `b10IsSupportDeviceOff` | 1 = 可由指令關機 |
| 11 | `b11IsSupportShowManual` | 1 = 顯示說明書 |
| 13 | `b13EQ` | > 0 = 支援 EQ；**數值是 EQ 方案編號**，決定預設列表，例如 `0x20`=古典/動態/人聲/自訂，`0x21`=流行/古典/搖滾/自訂，`0x23`=六組預設 |
| 14 | `b14Skin` | 外觀／UI 配置編號 |
| 16 | `b16Tap` | 觸控／按鍵配置編號 |
| 24 | `b24Lan` | 語言碼，用於 OTA 與提示音 |

## 位元組 0：基本型態

| 位元 | 意義 |
|------|------|
| 7 | TWS |
| 6 | 對耳（peer） |
| 5 | 右聲道 |
| 低 4 bit（`& 0x0F`） | `ancValue`；> 0 表示支援 ANC。bleVersion ≤ 1 時它就是 ANC 模式群組 |

備註：
- 位元組 19 的 bit4 起用「右移 4 位後 `(x & 1) != 1 或 x == -1`」判斷，邏輯是反的（該位元為 1 反而「不顯示」），別直接當旗標用。
- 位元組 27 沒有對應欄位。
- 「時間校正」在 20 / 21 / 26 重複出現，原碼同名，實際作用差異未查。
- 欄位名稱為官方原名的直譯，部分（如 `Btn`、`isQmxjc`、`DragonSound`）意義不明，不要憑名稱推測。

## 與已知指令的對應

| 旗標 | 對應指令 |
|------|----------|
| 位元組 2 / 4 / 5 | 名稱 `0xC9`、MAC `0xC8`、版本 `0xC6` |
| 位元組 13 | EQ `0xD5` / `0xC4`、自訂 EQ `0x43`–`0x47` |
| 位元組 17 bit0 | LED `0xF7`/`0xF8` |
| 位元組 18 bit1 / bit2 | LHDC `0x37`/`0x38`、LDAC `0x48`/`0x49` |
| 位元組 18 bit4 | 風噪 `0x5C`/`0x5D` |
| 位元組 21 bit2 | 降噪模式 `0x7F`/`0x80` |
| 位元組 22 bit0 | 高清編碼 `0x91`/`0x92` |
| 位元組 12 bit0–3、22 bit4 | OTA／DFU，**禁止觸碰** |
